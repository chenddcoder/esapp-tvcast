原型说明 · 已按 QuickTVUI / Hippy 支持的 CSS 子集实现

  • 操作：方向键移动焦点，回车选中；点击右上角胶囊切换「可投屏 / 投屏中」。
  • 图标：proto/icons/*.svg 共 13 个，原型用 img 加载（落地即 qt-image + 远端 SVG URL，失败兜底首字母）。
  • 光晕：radial-gradient 快应用不支持（现有首页的光晕其实没渲染出来），改用两个 linear-gradient 光带模拟。
  • 玻璃感：无 backdrop-filter，用 rgba 半透明底 + 1px 边框 + 顶部 1px 高光条模拟毛玻璃。
  • 阴影：单阴影 + 「容器比内容大 16px、内容绝对定位偏移」结构，兼容 Android 阴影容器遮挡模式。
  • 焦点态：原型用 class 模拟，落地用框架属性 focusScale / focusBorderColor / focusBorderWidth / focusBackgroundColor。
